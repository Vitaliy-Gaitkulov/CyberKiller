# CyberPink

Мобильная 2D мультиплеерная экшн-игра на Unity. Игроки подключаются через Photon PUN, управляют персонажем с оружием и способностями, сражаются на арене с респавном.

**Движок:** Unity 2020.3.30f1  
**Платформа:** Android (mobile)  
**Сетевой слой:** Photon Unity Networking v1 (PUN1)

## Что работает сейчас

- Подключение к Photon и создание/вход в комнату (с ожиданием `OnJoinedLobby`)
- Спавн игрока по сети (`PhotonNetwork.Instantiate`)
- Движение и прыжки через мобильный джойстик
- Стрельба: снаряд (`BulletTrail`) с уроном по RPC
- Щит: активируется вторым джойстиком, выключен при спавне
- Вращение руки по направлению стрельбы
- Смерть от падения за границу карты (визуальная линия в Editor на Y = fallBoundary)
- Респавн: игрок скрывается → таймер → телепорт на spawn point
- Параллакс фона, тряска камеры, следование камеры
- Система звуков через `AudioManager`
- Отображение пинга
- UI полоска здоровья

### Архитектурные

**6. Логика вращения руки продублирована**
`ArmRotation.cs` и `PlayerMove.cs` оба реализуют вращение руки по джойстику.

`Camera.main` вызывает `FindObjectOfType` каждый кадр. Нужно кешировать в `Start()`.

`WaveSpawner` и `Enemy` / `EnemyAI` находятся в `trash/` и не работают. Игра — только PvP без PvE контента.

**9. `PlayerStats.cs` — реген здоровья объявлен, но не реализован**
```csharp
public float healthRegenRate = 2f; // поле есть, но логики регена нет
```

**10. Отсутствует синхронизация вращения руки по сети**
В `PlayerMove.OnPhotonSerializeView` весь код закомментирован — другие игроки не видят, куда направлено оружие.

**11. Photon PUN v1 — устаревшая версия**
PUN v1 не поддерживается с 2018 года. Актуальная версия — PUN2 (`Photon.Pun` namespace).

## Переход на Unity 2022 LTS + PUN2

### Когда делать

После завершения Фазы 2. Делать это во время активной разработки геймплея — значит остановить её на неделю и получить новые баги. Оптимальный момент — перед Фазой 3 (полировкой).

### Почему нельзя просто обновить Unity

Сам движок (Unity 2020 → 2022 LTS) обновляется без проблем. **Единственный блокер — Photon PUN v1**, который не поддерживается с 2018 года и несовместим с современными версиями Unity. Все 9 сетевых скриптов используют PUN1 API.

### Шаг 1 — Миграция PUN1 → PUN2 (3–4 дня)

PUN2 доступен бесплатно через Asset Store (`com.exitgames.photon-unity-networking`). Основные замены:

| PUN1 | PUN2 |
|---|---|
| `Photon.MonoBehaviour` | `MonoBehaviourPun` |
| `PhotonTargets.AllBuffered` | `RpcTarget.AllBuffered` |
| `PhotonTargets.All` | `RpcTarget.All` |
| `photonView.isMine` | `photonView.IsMine` |
| `PhotonNetwork.playerName` | `PhotonNetwork.NickName` |
| `[PunRPC]` | `[PunRPC]` (без изменений) |
| `PhotonNetwork.room` | `PhotonNetwork.CurrentRoom` |
| `TypedLobby.Default` | `TypedLobby.Default` (без изменений) |
| `RoomOptions.maxPlayers` | `RoomOptions.MaxPlayers` |
| `OnConnectedToMaster()` | `OnConnectedToMasterServer()` через `IConnectionCallbacks` |
| `OnJoinedRoom()` | через `IMatchmakingCallbacks` |

**Файлы для изменения:** `Player.cs`, `Health.cs`, `Weapon.cs`, `DestroyBullet.cs`, `PlayerMove.cs`, `PlayerControls.cs`, `ArmRotation.cs`, `Camera2DFollow.cs`, `GameMaster.cs`, `MenuController.cs`

**Порядок действий:**
1. Создать ветку `migration/pun2`
2. Удалить папку `Assets/Photon Unity Networking/` (PUN1)
3. Импортировать PUN2 из Asset Store
4. Заменить все PUN1 API по таблице выше
5. Перепривязать `PhotonServerSettings` (новый формат)
6. Проверить все RPC — у PUN2 строже проверка сигнатур
7. Протестировать: спавн, стрельба, смерть, респавн, щит

### Шаг 2 — Обновление Unity 2020.3 → 2022.3 LTS (1 день)

После успешной миграции PUN2:

1. Скачать Unity 2022.3 LTS через Unity Hub
2. Открыть проект — Unity предложит конвертацию, согласиться
3. Исправить предупреждения компилятора (обычно 10–20 мелких)
4. Обновить пакеты в `manifest.json` до версий совместимых с 2022.3:
   - `com.unity.2d.animation`: `5.1.0` → `9.x`
   - `com.unity.textmeshpro`: `3.0.6` → `3.0.9`
   - `com.unity.2d.pixel-perfect`: `4.0.1` → `5.x`
5. Проверить сцены — иногда слетают ссылки на компоненты в префабах
6. Собрать тестовый APK

### Шаг 3 — Опционально: Photon Fusion 2 вместо PUN2 (2–3 недели)

Если в планах масштабирование или улучшение синхронизации — рассмотреть Photon Fusion 2. Это полная переработка сетевого слоя (не замена API, а другая архитектура: State Synchronization вместо RPC-центричной модели).

**Когда имеет смысл:** если PvP на 10+ игроков, нужна авторитетная физика или синхронизация анимаций.  
**Когда не нужен:** для текущего формата (2–5 игроков, простая арена) PUN2 полностью достаточен.

### Риски миграции

| Риск | Вероятность | Митигация |
|---|---|---|
| Слетели ссылки на компоненты в префабах | Средняя | Проверить каждый префаб в инспекторе после миграции |
| RPC не находит метод (сигнатура изменилась) | Высокая | Проверить все `[PunRPC]` методы вручную |
| `PhotonServerSettings` не читается | Низкая | Пересоздать через PUN2 Wizard |
| Анимационный контроллер слетел | Низкая | Сохранить бэкап ветки перед миграцией |

## Быстрый старт (для разработчиков)

1. Открыть проект в Unity 2020.3.30f1
2. Прописать Photon AppID в `Assets/Photon Unity Networking/Resources/PhotonServerSettings`
3. Открыть сцену `MainMenu`, запустить Play
4. Ввести имя, создать или войти в комнату — откроется `MainGame`

> **Важно:** кнопки создания/входа в комнату активны только после подключения к Photon Lobby. Статус отображается в поле `Status Text` (если подключён в инспекторе).
